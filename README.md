Maze Runner adalah game sederhana berbasis web yang dibuat menggunakan HTML, CSS, dan JavaScript. Dalam permainan ini, pemain harus menemukan jalan keluar dari labirin sambil menghindari rintangan yang tersedia. Proyek ini dibuat untuk melatih kemampuan dalam mengimplementasikan logika permainan, mengelola interaksi pengguna, serta mengembangkan antarmuka yang interaktif menggunakan JavaScript.

Fitur:
- Pergerakan karakter menggunakan keyboard
- Sistem navigasi dalam labirin
- Deteksi kemenangan saat mencapai tujuan
- Tampilan antarmuka sederhana dan responsif

Tech Stack:
- HTML
- CSS
- JavaScript

Tujuan Proyek:
Melatih kemampuan JavaScript melalui implementasi logika permainan, pengelolaan event pengguna, dan manipulasi elemen pada halaman web.
